資料集已改為只含 CC BY 4.0 來源並以來源群組切分；重訓後主模型 **EfficientNet-B0 @224 測試 Accuracy 80.16%（295/368）**。嘗試的 B2 @256 + 強增強只有 74.73%，**沒有改善**，因此不採用。舊的 92.5%、96.1% 已作廢，不可再引用。

## 2. 程式
- `build_dataset.py`：重寫，產生上述資料集，可重現。
- `config_classification.py`：預設 = 主模型配方（B0、224、`outputs_cc_by/`、不加強增強）。B2 實驗用環境變數：`WOOF_BACKBONE=efficientnet_b2 WOOF_IMG_SIZE=256 WOOF_STRONG_AUG=1 WOOF_OUTPUT_DIR=outputs_b2`。
- `train_classification.py`、`predict.py`、`gradcam_dermatophytosis.py`：支援 B2；訓練增強加入 `STRONG_AUG` 選項（RandomResizedCrop 最小比例 0.5、ColorJitter 0.4、RandomGrayscale 0.15、RandomErasing 0.25）。
- `main.py`（App 後端）：以修正版（`model_state_dict` 鍵名、`strict=True`、flip TTA、full backward hook）為基底，骨幹與輸入尺寸改由 `WOOF_BACKBONE`、`WOOF_IMG_SIZE` 控制，預設 B0/224；`/health` 回報 backbone 與 img_size。
- 新增 `verify_deploy_parity.py`（跨環境預測比對）、`gen_doc.py`（由 md 產生 docx/pdf）。
- 舊的 `merge_datasets.py`、`resplit_by_quality.py` 移到 `legacy/`。

## 3. 結果（測試集 368 筆，水平翻轉 TTA）
| 指標 | B0 @224（採用） | B2 @256 + 強增強 |
|---|---|---|
| Accuracy | **80.16%**（295/368） | 74.73%（275/368） |
| macro recall | 79.72% | 75.04% |
| macro F1 | 0.7932 | 0.7442 |
| weighted F1 | 0.7993 | 0.7475 |
| 驗證 Accuracy | 82.38% | 75.41% |

各類別 recall（靈敏度）：

| 類別 | B0 | B2 |
|---|---|---|
| healthy | 94.5 | 75.3 |
| hypersensitivity_dermatitis | 92.5 | 90.0 |
| bacterial_dermatosis | 88.7 | 79.2 |
| flea_allergy_dermatitis | 81.6 | 79.6 |
| mange | 68.4 | 65.8 |
| dermatophytosis | 67.9 | 60.7 |
| dermatitis | 64.4 | 74.6 |

- B2 只有 dermatitis 較好，其餘持平或變差。原因**未驗證**（可能是強增強加更大骨幹在 3,880 張資料下表現不佳，但未做消融實驗，依你的決定不做）。
- B0 的錯誤分析：已驗證 gabungan 來源最差（測試 74.7%、驗證 70.4%）、小圖與低對比度不是主因、高信心錯誤僅 2/73；類別與來源綁定造成捷徑學習、dermatitis/flea/dermatophytosis 視覺相似皆為推測。
- 測試集小、單次訓練（種子 42）、無信賴區間，各類別僅 38–73 筆，數字不確定性大；不構成臨床診斷效能。
