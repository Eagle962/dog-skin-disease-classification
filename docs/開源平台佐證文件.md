# 開源平台佐證文件

**專案名稱**：汪星人 AI 皮膚醫生（Dog Skin Disease Classification）
**文件日期**：2026-10-05
**專案性質**：以公開資料集與開源深度學習框架訓練之犬隻皮膚病影像分類模型（7 類），並以 Grad-CAM 標示病灶區域

---

## 一、專案概述

本專案整合 Roboflow Universe 上的公開犬隻皮膚病資料集，統一類別命名後重新切分（train/val/test = 75/15/10），以 PyTorch 之 ImageNet 預訓練 EfficientNet-B0 進行微調，輸出 7 類分類結果：

`bacterial_dermatosis`、`dermatitis`、`dermatophytosis`、`flea_allergy_dermatitis`、`healthy`、`hypersensitivity_dermatitis`、`mange`

並以 Grad-CAM 產生熱圖，標示模型判斷時關注的皮膚區域。

### 類別整合方式
`merge_datasets.py` 內的 `CLASS_ALIAS` 將各資料集不同命名統一，例如：
`ringworm` / `fungal infection` → `dermatophytosis`；`scabies` / `demodectic mange` → `mange`；`flea` → `flea_allergy_dermatitis`。
並以雜湊（hashlib）去除重複影像，再依品質稽核（`audit_image_quality.py`、`resplit_by_quality.py`）重新切分。

## 四、技術流程與開源元件對應

| 階段 | 腳本 | 使用的開源元件 |
|---|---|---|
| 資料下載與合併 | `merge_datasets.py` | roboflow SDK、PyYAML、Pillow、Matplotlib |
| 標註修補 | `patch_annotations.py` | Python 標準函式庫 |
| 影像品質稽核 | `audit_image_quality.py` | OpenCV、Pillow、NumPy |
| 依品質重新切分 | `resplit_by_quality.py` | NumPy、scikit-learn |
| 設定檔 | `config_classification.py` | PyTorch |
| 模型訓練與評估 | `train_classification.py` | PyTorch、torchvision、scikit-learn、Matplotlib |
| 推論與 Grad-CAM | `predict.py`、`gradcam_dermatophytosis.py` | PyTorch、torchvision、OpenCV、Matplotlib |

### 模型與訓練設定（取自 `config_classification.py`）
- 骨幹：EfficientNet-B0（torchvision，ImageNet 預訓練），輸入 224×224
- 優化：Batch 32、60 epochs、lr 1e-3、weight decay 2e-3、cosine 排程 + 3 epoch warmup
- 抗過擬合：Label smoothing 0.1、Focal Loss（γ=2）、MixUp / CutMix、前 5 epoch 凍結骨幹、early stopping
- 評估：Accuracy、Precision、Recall、F1、混淆矩陣、ROC / PR 曲線、水平翻轉 TTA
- 隨機種子：42（可重現）

## 五、使用方式

```bash
pip install torch torchvision scikit-learn numpy pillow opencv-python-headless matplotlib tqdm pyyaml roboflow
export ROBOFLOW_API_KEY=<your key>   # 自行至 Roboflow 取得
python3 merge_datasets.py            # 下載並合併資料集
python3 train_classification.py      # 訓練與評估
python3 predict.py path/to/image.jpg # 推論並產生 Grad-CAM
```
