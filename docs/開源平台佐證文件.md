文件日期：2026-10-12（修訂版，補入重新訓練結果與切分稽核，取代 2026-10-10 版）

專案性質：以公開、具明確開放授權之資料集與開源深度學習框架訓練之犬隻皮膚病影像分類模型（7 類），並以 Grad-CAM 標示病灶區域

## 一、專案概述

本專案整合 Roboflow Universe 上 4 個 CC BY 4.0 授權的公開犬隻皮膚病資料集，統一類別命名後，去除完全相同與近似重複的影像，剔除旋轉擴增造成的黑邊影像，再以「來源群組」方式切分為 train / val / test（3,880 / 488 / 368，共 4,736 筆，比例約 82 / 10 / 8）。以 PyTorch 之 ImageNet 預訓練 EfficientNet-B0 進行微調，輸出 7 類分類結果：

bacterial_dermatosis、dermatitis、dermatophytosis、flea_allergy_dermatitis、healthy、hypersensitivity_dermatitis、mange

並以 Grad-CAM 產生熱圖，標示模型判斷時關注的皮膚區域。

注意：本版資料集已排除先前使用之授權未確認來源，模型已以本資料集重新訓練，結果見第四節；本文件不引用舊模型（含授權未確認來源之資料）之任何準確率。

### 類別整合與資料處理

build_dataset.py 內的 ALIAS 將各資料集不同命名統一為 7 類，例如：ringworm / fungal infection → dermatophytosis；scabies → mange；flea-allergy / flea_allergy → flea_allergy_dermatitis；hypersensitivity-allergic-dermatosis → hypersensitivity_dermatitis。不在 7 類內的標籤（如 Smoky 的 tumor）一律丟棄。處理步驟：

1. YOLO 偵測資料依標註框裁切（外擴 15%）；folder 資料取整張。
2. 剔除旋轉擴增殘留的黑色三角邊影像（共 594 張：litespy 305、smartdog 213、gabungan 55、smoky 21），並剔除 Smoky 邊長小於 64 px 的裁切（8 張）。
3. 以 MD5 去除完全相同影像；以 pHash 距離 ≤ 6 且 32×32 灰階像素相關係數 ≥ 0.9 去除跨來源之近似重複影像（共 37 張）。
4. 同一來源影像檔的多個裁切、描述性檔名相同者、近似重複者視為同一群組，整組分入同一個 split，各類別依比例分層，避免訓練／測試洩漏。分組比對涵蓋 8 種方向（旋轉 90 度倍數與水平鏡像）及 ±3/5/7/10/15° 小角度旋轉，pHash 或 dHash 任一近似（距離 ≤ 8）且 32×32 灰階相關係數 ≥ 0.9 即視為同組，雙向比對，低對比度影像也參與分組。（先前版本只比對 0/90/180/270 度，稽核發現測試集有 62/368＝16.8% 在訓練集有鏡像或小角度旋轉的近重複副本，故改版；舊切分的 80.16% 不再作為主要結果。）
5. 每筆樣本於 manifest.csv 記錄來源專案與原始檔名，可追溯。


### 已知限制

- litespy 影像小（≤128×128）且多數呈單一色版色偏，病灶細節少；這類近單色影像（本資料集約 734 張）的近似重複偵測不可靠，無法保證其未跨 split 重複。
- 高對比度影像經獨立檢查，跨 split 的經驗證近似重複為 0；低對比度影像之相似度配對（約 97 對）屬不可靠比對，不視為已證實的重複。
- 已移除授權不明來源後，浮水印圖庫照片未經偵測與處理，資料中可能仍有此類影像（受來源作者授權聲明約束，本專案無法獨立查證）。
- 新切分的巨大群組（見上）使 litespy 與 smoky 的 val/test 筆數很少（litespy 測試 40、smoky 測試 14），來源別準確率不穩定。
- 資料集規模（4,736 筆）小於先前版本，且各來源之類別與影像類型混淆，模型表現不宜歸因於影像類型。
- 上傳於 Roboflow 的影像若原為網路蒐集，其原始著作權狀態以各資料集作者之授權聲明為準，本專案無法獨立查證。

### 模型與訓練設定（取自 config_classification.py）

- 骨幹：EfficientNet-B0（torchvision，ImageNet 預訓練），輸入 224×224
- 優化：AdamW、Batch 32、60 epochs、lr 1e-3、weight decay 2e-3、3 epoch warm-up 後 cosine 至 1e-6
- 抗過擬合：Label smoothing 0.1、Focal Loss（γ=2，類別權重）、WeightedRandomSampler、MixUp(α0.2) / CutMix(α1.0)（機率 0.5）、前 5 epoch 凍結骨幹、early stopping（監控驗證 loss，patience 15，可用 WOOF_PATIENCE 覆寫）；依驗證集 weighted F1 選模型
- 評估（測試集）：Accuracy、Precision、Recall、F1、混淆矩陣、ROC / PR 曲線、水平翻轉 TTA
- 隨機種子：42（固定種子，但 MPS 後端不保證逐位元重現）

**切分歷程與對照（皆為單次訓練，種子 42）：**

| 版本 | 切分 | 測試 Accuracy | 備註 |
|---|---|---|---|
| 舊切分（只比對 0/90/180/270 度） | 舊 | 80.16%（295/368） | 稽核發現 62/368（16.8%）測試影像在訓練集有鏡像／小角度旋轉的近重複副本；有近重複者 56/62＝90.3%，無近重複者 239/306＝78.1% |
| 新切分，early stopping patience 8 | 新 | 66.30%（244/368） | epoch 19 即停止、訓練 Accuracy 約 73%，疑為欠擬合 |
| **新切分，patience 15（主結果）** | 新 | **77.72%（286/368）** | 放寬 patience 是看到 66.30% 後才決定，依據驗證集而非測試集，但屬於事後調整，應如實揭露 |

新舊切分的測試集組成不同（例如 litespy 測試筆數 82→40），不能直接逐項比較。

**B2 對照實驗（舊切分上進行，未在新切分重做）：** EfficientNet-B2 @256 搭配較強資料增強，在舊切分上測試 Accuracy 74.73%（275/368）、macro F1 0.7442，低於同切分的 B0（80.16%），故採用 B0。此對照不適用於新切分。

誤差分析（舊切分、舊模型時得到的觀察，不保證適用於新模型）：gabungan 準確率最低、小圖與低對比度不是主因、高信心錯誤僅 2/73。新模型的各來源準確率見上表（smartdog 最高）。patience 8 版本曾出現 healthy 大量被判為 hypersensitivity（litespy 佔訓練集 healthy 的 477/773），顯示可能存在來源捷徑，但 patience 15 版本此現象大幅減輕，且未做消融實驗，故不下結論。標註正確性未經獸醫審核。

測試集僅 368 筆，單次訓練，未做信賴區間或多種子重複；各類別 38–73 筆，類別層級數字的不確定性大。此結果為研究原型的離線評估，不構成臨床診斷效能。

切分稽核：以 pHash／dHash 加 32×32 像素相關比對（含鏡像與 ±3–15° 小角度旋轉），新切分的測試集在訓練集中找到的近重複為 0 筆。但分組所用方法與此稽核方法重疊，這個 0 不是獨立證明；影片影格等其他類型的副本未檢查。

Grad-CAM 範例（B0、新切分、測試集）：`gradcam_example_B0_ccby.png` 為預測正確且熱圖落在發紅皮膚區域的樣本（挑選過，非隨機）；`gradcam_counterexample_B0_ccby.png` 為預測正確但熱圖偏向右側而非傷口的樣本，Grad-CAM 不能保證標出病灶。

## 五、使用方式

```bash
pip install -r requirements.txt
export ROBOFLOW_API_KEY=<your key>   # get your own key from Roboflow
python3 download_sources.py          # download the 4 source datasets
python3 build_dataset.py             # build dataset_cc_by/
python3 patch_annotations.py         # check dataset vs config
python3 train_classification.py      # train and evaluate (default: EfficientNet-B0 @224)
python3 predict.py path/to/image.jpg # predict + Grad-CAM
```

B2 對照實驗：`WOOF_BACKBONE=efficientnet_b2 WOOF_IMG_SIZE=256 WOOF_STRONG_AUG=1 WOOF_OUTPUT_DIR=outputs_b2 python3 train_classification.py`。App 後端 `main.py` 以環境變數 `MODEL_PATH`、`WOOF_BACKBONE`、`WOOF_IMG_SIZE` 設定，預設 B0 / 224。
